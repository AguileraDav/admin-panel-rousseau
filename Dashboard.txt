Dashboard

- Alimentos -

Tabla con cada dia para agregar la comida. Cada dia tendra 3 elementos: Comida, postre y agua

- Documentos importantes - 
El documento debe aparecer en el dashboard y se debe poder aceptar la solicitud de ellos

- Calendario -
Opcion con calendario para agregar los periodos de cada ciclo escolar. Como inicio de clases, vacaciones, dias inhabiles, etc... Estara la opcion para agregarlo con colores, periodo y poner el titulo

- Asistencia -
En asistencia habra un menu donde se pueda registrar la asistencia y con iconos para colocar si asistio o no

- Calificaciones -
Deben aparecer las materias y la opcion para poner la calificacion de cada una. 

- Galeria -

Opcion para subir imagenes

- Solicitudes -

Las solicitudes de los mensajes que se envien de la app deben llegar al dashboard
